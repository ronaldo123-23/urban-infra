# 「진짜일까?」 판정 개선 계획

파트너(Codex)의 계획서와 geonhee(Claude)의 분석을 합친 문서예요. 2026-11-22에 배포본(https://urban-infra-jet.vercel.app)에서 실제 게시물로 확인한 결과를 바탕으로 했어요.

## 목표
게시물의 핵심 주장을 끝까지 찾아 검증하고, **원문에서 확인한 내용**, **원문과 다른 내용**, **근거가 부족해 판단을 보류한 이유**를 사용자에게 보여준다. 유료 AI 없이 규칙으로 할 수 있는 것부터 한다.

## 1. 출발점 (마라톤 게시물 실측)
게시물: https://www.instagram.com/p/DftueIimQQx/ (캡션 519자, 메타 태그로 전부 읽힘)

판정 대상으로 고른 5개:
1. "러닝 전에 먹으면 신장에 무리 주는 약," → 제목 조각
2. "탁센·이지엔6 같은 소염진통제(NSAIDs)" → 제목 조각
3. "러닝을 하면 땀으로…탈수가 오기 쉽습니다" → 일반 상식
4. "NSAIDs는 신장 혈류를 줄여…" → 일반 설명
5. "급성 신부전으로 이어지는 사례도…" → 일반 설명

정작 검증해야 할 **"18% 더 높은"(연구 수치)**과 **"48시간 전부터"(공식 가이드)**는 6번째 이후라 빠짐. 관련 자료에 "강아지 신부전" 같은 엉뚱한 기사가 섞임. 5개 모두 "아직 확인 안 됨".

## 3. 개선안

### PR A — 주장 고르기와 보류 이유 (①②⑥) — `geonhee/claim-selection`
- 캡션 전체를 훑고 우선순위를 매긴다: 수치·날짜·출처("연구에서", "~교수는", "공식 가이드", "~에 따르면")가 있는 문장 먼저.
- 걸러낼 것: 제목 조각(쉼표로 끝나거나 서술어로 끝나지 않는 줄), 질문, 의견, 조언·권유, 소개 문장("~소식입니다", "~했는데요", "~알아볼게요"). 걸러낸 문장은 카드 대신 "검증에서 뺀 문장" 목록에 이유와 함께 보여준다.
- 같은 내용 반복은 하나로 묶는다.
- 5개씩 검증하고 남은 개수를 보여준다. "나머지 주장 검증" 버튼으로 이어서 확인한다.
- 보류 이유 3가지:
  - `search_not_run` — "뉴스 검색이 실행되지 않았어요"
  - `no_results` — "관련 자료를 찾지 못했어요"
  - `insufficient_match` — "관련 기사는 찾았지만 이 주장을 확인할 근거 문장을 찾지 못했어요"

### PR B — 원문 찾기와 대조 (③④⑤⑦) — PR A 머지 후
- 원문 확보: 찾은 기사·공식 페이지 본문을 서버에서 가져와 대조. 근거로는 한두 문장만 인용하고 링크를 함께 보여준다 (저작권).
- 검색처 넓히기 (무료): 공식 기관 페이지는 네이버 웹문서 검색(같은 API HUB 키), 해외 연구는 Europe PMC / PubMed(무료, 키 없음). 한→영 검색은 의학·통계 용어 사전으로(예: 이부프로펜→ibuprofen, 급성 신손상→acute kidney injury, 울트라마라톤→ultramarathon). 사전에 없으면 영어 검색 안 함.
- "확인됨"/"근거와 다름"은 원문에서 같은 대상·시점·조건의 수치나 명시적 문장을 찾았을 때만. 비교 항목, 근거 문장, 링크를 표시한다.
  - 수치 예: 게시물 "18% 더 높다" vs 원문 "52% 대 34%" → "18%포인트 차이예요(비율로는 약 53% 높음)"로 설명하고 불확실성 표시.
  - 조건이 같은지 규칙으로 알 수 없으면 보류 (틀린 판정보다 보류가 낫다).
- 관련 자료 거르기 강화: 아래 **3-1 연관성 기준**으로 점수를 매겨 "직접 근거 / 관련 자료 / 무관"으로 나눈다.
- 받아쓰기 묶음은 지금처럼 1개 출처로 센다.
- 한계: 규칙으로 잡을 수 있는 건 수치가 있는 주장과 원문에 같은 문장이 있는 주장까지. 일반 설명문은 여전히 보류가 많을 것.

### 3-1. 게시물 주장 ↔ 기사 연관성 기준
지금 규칙은 단어 몇 개만 겹쳐도 관련 기사로 봐서, "신부전"이 겹친다는 이유로 "강아지 신부전" 기사가 마라톤 게시물에 붙었다. 무엇이 겹쳐야 하는지 항목별로 나눠 AI 없이 계산한다.

**1단계 — 주장에서 6가지 항목 뽑기**
| 항목 | 뜻 | 마라톤 예시 (18% 주장) |
|---|---|---|
| 주제어 | 무엇에 대한 이야기인지 (고유명사, 약·질병·기관 이름) | 이부프로펜, 급성 신손상, 울트라마라톤 |
| 대상 | 누구·무엇에 해당하는지 | 울트라마라톤 참가자 (사람) |
| 수치 | 숫자 + 단위 | 18% |
| 시점 | 날짜, 기간, "작년·내년" | (없음) |
| 출처 | 게시물이 인용한 연구·기관·사람 | "연구에서" |
| 관계 | 무엇이 어떻게 됐는지 | 위험이 높다 |

**2단계 — 관문 2개 (하나라도 실패하면 "무관")**
1. 주제어 관문: 기사 제목에 주제어 2개 이상, 또는 제목 1개 + 본문(요약) 2개 이상. 같은 말 사전을 함께 쓴다 (예: 소염진통제 = NSAIDs, 급성 신손상 = 급성 신장 손상 = AKI, 이부프로펜 = ibuprofen).
2. 대상 충돌 관문: 기사의 대상이 주장과 분명히 다르면 탈락 — 사람 ↔ 동물(강아지·고양이·반려동물), 지역(서울 ↔ 부산), 나라(한국 ↔ 미국), 집단(청년 ↔ 노인, 어린이 ↔ 성인).

**3단계 — 연관도 점수 (100점)**
| 항목 | 점수 | 계산 |
|---|---|---|
| 주제어 일치 | 40 | 겹친 주제어 비율 × 40 (제목에 있으면 2배로 셈) |
| 수치 일치 | 20 | 같은 숫자·단위가 기사에 있으면 20. 주장에 수치가 없으면 이 항목을 빼고 나머지로 100점 환산 |
| 출처 일치 | 15 | 게시물이 인용한 기관·사람·연구 이름이 기사에 있음 |
| 대상 일치 | 15 | 같은 대상이 기사에 명시됨 |
| 시점 일치 | 10 | 주장의 날짜·연도가 기사에 있거나 기사 날짜가 주장 시점과 맞음 |

**4단계 — 등급과 쓰임**
| 등급 | 조건 | 쓰임 |
|---|---|---|
| 직접 근거 | 70점 이상. 주장에 수치·출처가 있으면 그것도 일치해야 함 | 판정 근거로 쓸 수 있음 |
| 관련 자료 | 40~69점 | "관련 자료" 목록에만 표시, 판정에는 안 씀 |
| 무관 | 40점 미만 또는 관문 실패 | 화면에 안 보여줌 |

화면에는 왜 연관 있다고 봤는지도 보여준다 (예: "일치: 이부프로펜 · 울트라마라톤 · 18%").

**지금까지 사례에 적용하면**
| 주장 | 기사 | 결과 |
|---|---|---|
| "급성 신부전으로 이어지는 사례도…" | 강아지 신부전, 초기 증상 놓치기 쉬워… | 무관 (대상 충돌: 사람 ↔ 강아지) |
| "행사는 11월 20일부터 22일까지…" | [출근길 브리핑] 李 '가짜뉴스 팩트체크' 예산 확대… | 무관 (제목에 주제어 없음) |
| "동물카페가 내년에 전부 폐업한다고…" | 동물카페 내년에 전부 폐업한다? | 직접 근거 (제목에 주제어 4개, 시점 '내년' 일치) |
| "울트라마라톤…이부프로펜…18% 더 높은" | 울트라마라톤·진통제·신장 일반 기사 | 관련 자료 (18%가 기사에 없음) → 논문 원문에서 수치를 찾으면 직접 근거 |

**한계**: 말을 바꿔 쓴 기사는 같은 말 사전에 없으면 놓친다. 대상 충돌은 사전에 넣은 경우만 잡는다 (처음엔 사람·동물, 지역, 나라, 나이대). 원문을 읽기 전에는 제목과 100자 요약으로 계산한다.

### PR C — 판정 정확도 (일반 계정 정치·시사·경제 게시물로 시험) — `geonhee/verify-accuracy`
배경: 인스타 #경제뉴스·#시사·#정치의 일반 계정 게시물 6개를 실제 기사와 대조해 보니, 5개는 기사로 확인되는 내용인데 서비스는 거의 다 "아직 확인 안 됨"이었고 잘못된 "확인됨"도 1건 있었다 (배포본 1/6).

| 원인 | 고친 것 |
|---|---|
| 검색어가 긴 단어 위주라 숫자·고유명사가 빠짐 ("6515조", "13명") | 검색어 3가지: 큰 숫자+핵심어 / 핵심어 3개 / 팩트체크+핵심어 |
| 조·억 단위, 쉼표 숫자를 못 읽음 | "6,515조 원" = "6515조원"으로 인식 |
| 따옴표·말줄임표에서 문장이 조각남 | 따옴표·괄호 안에서는 자르지 않음 |
| 발언 인용 주장을 자료 제목 한 줄로 확인 | 따옴표 안 핵심어가 원문 한 문장에 모두 있어야 확인, 제목·메뉴 줄 제외 |
| (시험 중 발견) 숫자만 같고 내용은 반대인 기사로 확인 ("23만명 돌파…증가율 최고") | 최저↔최고, 증가↔감소 반대 말 검사 |
| (시험 중 발견) 검색어가 바뀌자 팩트체크 요약에 반박 표현이 안 나옴 | 읽은 본문에서도 반박 문장을 찾음 |
| 직책이 바뀐 걸 모름 (젠슨 황 "전 CEO") | 최신 자료에 "전 ○○"이 있으면 비교 설명으로 안내 |

결과: 로컬 6/6, 이전 시험(마라톤 2개 확인, 소문 3개 반박, 시점 규칙, 자료 없음) 그대로. 시험 세트: `docs/test-sets/politics-economy.json`, 실행: `node scripts/verify-sample.mjs`.
남은 한계: "[속보]… 결정"처럼 예전부터 이어진 상태를 새 소식처럼 쓴 틀은 못 잡음 (지금은 "아직 확인 안 됨"). 규칙으로 맞춘 부분이 있어 시험 세트 밖 게시물에서는 성적이 낮을 수 있음.

## 5. 확인 방법
- [x] 마라톤 게시물에서 18%와 48시간 주장 모두 첫 검증 목록에 들어간다 (PR A, 로컬 확인: 48시간 1순위, 18% 2순위)
- [x] 제목 조각·소개 문장이 판정 카드로 나오지 않는다 (PR A, 로컬 확인: 마라톤 제목 조각 2줄이 "검증에서 뺀 문장"으로)
- [x] 키가 없을 때 / 검색 결과가 없을 때 / 관련 기사만 있을 때 다른 안내가 나온다 (PR A, 로컬 확인)
- [x] 이전 시험의 소문 3개(동물카페, 해외주식, 스타벅스)는 여전히 반박 판정 (PR A, PR B 로컬 확인)
- [x] 18%를 "52% 대 34%, 18%포인트 차이"로 설명하고 불확실성 표시 (PR B 로컬 확인: 논문 초록 인용, "95% 신뢰구간 -4%~41%로 0을 포함" 표시)
- [x] 48시간 주장에 공식 안내의 "대회 전 48시간·대회 중·대회 후 48시간"을 보여준다 (PR B 로컬 확인: TCS London Marathon 공식 의료 안내 원문 인용)
- [x] 같은 기사가 여러 매체에 실려도 근거 수가 부풀려지지 않는다 (받아쓰기 묶음 유지, 확인·반박 판정은 자료 1개로 냄)
